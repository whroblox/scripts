# 🧪 _template — шаблон скрипта WhiteCheats

Как завести новый скрипт:

1. Скопируй эту папку и назови её именем скрипта (`kebab-case`, например `local-npc`, `xp-view`).
2. Отредактируй `manifest.json` — это карточка в loader'е (имя, описание, версия).
3. Открой `main.lua` — напиши свою логику (или укажи другой файл в поле `entry`).
4. Замени `icon.svg` на свою иконку (`viewBox="0 0 512 512"`).
5. Закоммить и запуш — loader сам увидит новую папку и покажет карточку.

⚠️ Папки с префиксом `_` loader не показывает — поэтому шаблон живёт здесь.
⛔ Эмодзи в `.lua` запрещены. Символы и SVG — можно.
