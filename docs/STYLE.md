# 📘 STYLE.md — правила оформления WhiteCheats

Этот документ — закон для всего, что мы публикуем.

---

## 1. Три уровня оформления

| уровень | разрешено | запрещено |
| --- | --- | --- |
| **Аккаунт GitHub** (имя, био, статус) | эмодзи, символы | — |
| **Репозитории** (README, описания) | эмодзи и символы **только** в `.md` / `.txt` | эмодзи в коде и в именах файлов |
| **Скрипты** (`.lua` и прочий код) | символы (`• ✦ ⟳ ✕ ●` …), SVG-иконки | **эмодзи — строго запрещены** |

Проверка перед пушем: ни один `.lua` не должен содержать emoji-символы (U+1F000+ и т.п.).

## 2. Структура репозитория `scripts`

```
scripts/
├── loader.lua              ← загрузчик, лежит в корне
├── catalog.json            ← резервный каталог
├── assets/                 ← логотипы (png/svg)
├── _template/              ← шаблон скрипта (префикс "_" = системная папка)
├── docs/                   ← документация
└── {имя-скрипта}/          ← одна папка = один скрипт
    ├── manifest.json       ← карточка скрипта (обязательно)
    ├── main.lua            ← точка входа (или свой файл + поле entry)
    ├── icon.svg            ← иконка карточки
    └── README.md           ← описание скрипта (эмодзи можно)
```

- Имя папки скрипта: **kebab-case**, латиница, без пробелов — например `local-npc`, `xp-view`.
- Папки с префиксом `_` loader не показывает — там живут системные вещи (`_template`).
- Ничего лишнего в корне: файлы скрипта живут в своей папке, а не в корне репо.

## 3. manifest.json

```json
{
  "id": "local-npc",
  "name": "Local NPC",
  "version": "1.0.0",
  "author": "WhiteCheats",
  "description": "Что делает скрипт — одно-два предложения.",
  "entry": "main.lua",
  "icon": "icon.svg",
  "tags": ["visual", "client-only"],
  "hidden": false
}
```

- `version` — только семвер: `MAJOR.MINOR.PATCH`.
- `description` — человеческий язык, без спама символами.
- `hidden: true` — скрипт не попадает в каталог loader'а.

## 4. Код (`.lua`)

- Только **client-side**. Никакого вреда игре и игрокам — это философия WhiteCheats.
- **Эмодзи запрещены.** Символы (`•`, `✦`, `⟳`, `✕`, `●`, `—`) и SVG — можно.
- Комментарии — на русском, по делу.
- Имена переменных — латиница, `snake_case` или `camelCase`, единообразно внутри файла.
- Шапка файла: блок-комментарий с названием, версией, что делает и как работает.
- Ошибки пользователя — через `pcall` + понятные сообщения, никаких молчаливых падений.

## 5. SVG-иконки

- `viewBox="0 0 512 512"`.
- Без внешних шрифтов и внешних картинок — только примитивы (path, rect, circle, polyline).
- Стиль: белый щит + фиолетово-циановый акцент (`#8b5cf6` → `#22d3ee`), тёмное стекло (`#111116` … `#1c1c26`).

## 6. Философия WhiteCheats

Мы делаем **белые** скрипты: XP View, Local NPC и другие утилиты, которые не вредят игре и игрокам. Fly, Noclip, Fling, kill-эксплойты и прочая деструктивщина — не наш путь. Одна папка — один скрипт, один смысл.
