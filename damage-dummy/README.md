# ✦ Damage Dummy

**Локальный манекен для теста урона — виден только тебе**

Остальные игроки видят, как будто ты стреляешь в пустоту. А у тебя — полноценный NPC-манекен: попадай по нему, смотри урон, DPS и лог попаданий.

</div>

---

## Что умеет

| блок | настройки |
| --- | --- |
| Внешность | R6-манекен или клон твоего персонажа (R15/R6), имя, цвет кожи, футболка / штаны по ID, волосы и аксессуары по ID |
| Движение | стоит / бродит / следует за тобой, WalkSpeed 0–100, JumpPower 0–200, радиус брожения |
| Тест урона | лог попаданий с таймингом, суммарный урон, DPS за окно 5 секунд, всплывающие числа урона, полоска HP над головой |
| Прочее | god mode, авто-респаун с задержкой, лечение, сброс статистики, подсветка манекена |

Манекен существует только на твоём клиенте: его не видно другим игрокам, сервер его не знает. Позиция спавна — перед персонажем или в точку прицела.

## Запуск

Через loader — кнопка `INJECT` на карточке. Или отдельно:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/whroblox/scripts/main/damage-dummy/main.lua"))()
```

`RightShift` — показать / скрыть панель.

## Настройки

Сохраняются локально (`whitecheats_damage_dummy.json`) через `readfile`/`writefile`, если executor их поддерживает. Кнопка `THEME` в шапке переключает dark / white.
