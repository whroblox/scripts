# ✦ Damage Dummy

**Локальный манекен для теста урона — виден только тебе**

Остальные игроки видят, как будто ты стреляешь в пустоту. А у тебя — полноценный NPC-манекен: попадай по нему, смотри урон, DPS и лог попаданий.

</div>

---

## Что умеет

| блок | настройки |
| --- | --- |
| Внешность | R6-манекен или клон твоего персонажа (R15/R6), имя, цвет кожи, футболка / штаны по ID, волосы и аксессуары по ID |
| Движение | стоит / бродит / следует за тобой, WalkSpeed 0–100, JumpPower 0–200, радиус брожения |
| Тест урона | hit-детектор (клик → raycast → урон), лог попаданий с частью тела и дистанцией, суммарный урон, DPS за окно 5 секунд, всплывающие числа урона, полоска HP над головой |
| Прочее | headshot x2 (эмуляция), god mode, авто-респаун с задержкой, лечение, сброс статистики, подсветка манекена |

## Как считается урон

Сервер не видит локальный манекен, поэтому в v1.1.0 урон считается на клиенте двумя каналами:

1. **Пассивный** — если игра сама наносит урон манекену (клиентский damage), попадание логируется как есть.
2. **Hit-детектор** — каждый клик превращается в raycast от камеры. Попал в манекен — урон. Значение берётся из твоего Tool (атрибут или `Value` с именем `Damage` / `DMG`); если оружие его не сообщает — применяется **TEST DAMAGE** (слайдер), такие попадания помечаются `est`.

Кнопка `TEST HIT` сразу применяет тестовый урон без стрельбы. Манекен существует только на твоём клиенте: его не видно другим игрокам, сервер его не знает. Позиция спавна — перед персонажем или в точку прицела.

## Запуск

Через loader — кнопка `INJECT` на карточке. Или отдельно:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/whroblox/scripts/main/damage-dummy/main.lua"))()
```

`RightShift` — показать / скрыть панель.

## Настройки

Сохраняются локально (`whitecheats_damage_dummy.json`) через `readfile`/`writefile`, если executor их поддерживает. Кнопка `THEME` в шапке переключает dark / white.
